ENEMY EDITOR — CONTENT PIPELINE PLAN
=====================================

WHAT THIS IS
------------
A standalone authoring tool that outputs enemy JSON files.
The game itself does NOT change — it still reads the same flat JSON it always has.
This is a creation convenience, not a runtime system.

The key idea: the editor has a shared move pool you pick from and tweak per enemy.
When you're done, a bake/export step resolves everything and writes the final JSON
into the game's data folder. The game never knows the pipeline existed.

This is called a "content pipeline" — common in game dev (Hades, Diablo, Quake etc.)
Author in a richer format → compile down to a simpler runtime format.


WHAT THIS IS NOT
----------------
- NOT reorganizing the existing enemy JSON files
- NOT making the game reference a shared move pool at runtime
- NOT changing how battle_engine.js reads or processes enemies
- NOT adding complexity to the game logic side at all

The duplication in the JSON files stays. It just becomes managed duplication
generated by a tool rather than hand-copied manually.


PHASES
------

Phase 1 — Shared Move Pool
- Define a master move_pool.json that lives OUTSIDE src/
- Each move has its full default definition (same shape as action_library entries today)
- This is the editor's source of truth only

Phase 2 — Enemy Template Authoring
- Author enemies by referencing move names from the pool
- Specify per-enemy overrides (power, speed_mod, dodge_range, cost, etc.)
- The template file stays lean — just identity + overrides on top of defaults

Phase 3 — Bake / Export Script
- Node.js script reads the template, resolves move references, merges overrides
- Outputs fully baked enemy JSON into src/data/characters/factions/
- This is the same JSON the game reads today — no game changes needed

Phase 4 — Editor UI (optional, later)
- Visual front-end on top of the bake script
- Pick moves from pool, tune values, preview the enemy, hit export
- Designers stay in a friendly UI, game stays dumb


BENEFIT
-------
- Renaming or restructuring a move? Change it in the pool, rebake.
- Creating a new faction member? Start from pool moves, tune values, export.
- One-off weird enemy? Still just write the JSON by hand. The pipeline doesn't own you.
